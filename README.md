# Ohisama Sushi

Production marketing site for Ohisama Sushi, 39 Paddington Street, Marylebone W1U 4HH.

Stack: Next.js App Router · TypeScript · Tailwind CSS · Framer Motion  
GitHub Pages slug: `ohisama-sushi-demo` (`basePath` / `assetPrefix`)

```bash
npm install
npm run dev    # http://localhost:43137/ohisama-sushi-demo/
npm run build  # static export → out/ (+ .nojekyll)
```
